HOW TO INSTALL

  1. Download the .zip from the mod's Releases page — take the file named for the mod, not the source archive.
  2. In Gen1Recomp, open MODS and choose Import mod .zip. Dropping the file onto the launcher window works too.
  3. Enable the mod, then start your game. Already installed? MODS → Check for updates finds new versions on its own.
