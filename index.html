Rigged Game Corner

v0.1.0 GOLD

Win every time at Goldenrod's Game Corner. The slots line up three 7s for the 300-coin jackpot on every spin, and Card Flip turns over a card that always matches the square you bet — both with the reels and cards honestly showing the win. You still pay to play; you just stop losing. Two toggles, one per game, both on by default.

HOW TO INSTALL

  1. Download the .zip from the mod's Releases page — take the file named for the mod, not the source archive.
  2. In Gen1Recomp, open MODS and choose Import mod .zip. Dropping the file onto the launcher window works too.
  3. Enable the mod, then start your game. Already installed? MODS → Check for updates finds new versions on its own.
